About this project

What the project is for, what it can do today, and what it cannot do.

Project objective

This is a first mini project on medical image analysis. The goal is a complete workflow (upload, analyze, review) for chest X-ray images, with the long-term aim of a binary classification: Normal vs. Pneumonia. This version builds only the user interface.

Technologies used

  • HTML5 for the page structure
  • CSS3 for layout and styling (one shared stylesheet)
  • Vanilla JavaScript (one shared file), using the browser File API, sessionStorage and Blob downloads
  • No frameworks, no libraries and no build step

Current features

  • Demo sign-in and sign-up screens with form validation
  • PNG and JPEG upload with type and size checks (2 MB limit)
  • Image preview with file name, type and size
  • Brightness, contrast, zoom and rotation display controls, plus a brightness histogram
  • Sample report page with a downloadable text file
  • Responsive layout for desktop, tablet and phone

Current limitations

  • No AI. Nothing here analyses an image or predicts a condition.
  • No real security. The sign-in screens are a demo. Passwords are not checked or stored.
  • Display controls are browser CSS filters, not medical image enhancement.
  • The image is kept only in the current browser tab and is limited to small files.
  • The report is a sample layout and contains no findings.
  • Not a medical device. Not for diagnosis or clinical use.

Future integration with Python

A Python backend (for example Flask or FastAPI) can receive the image from this frontend, resize and normalise it with a library such as Pillow or OpenCV, run the model and send the result back to the report page. Real sign-in and account handling would also move to this backend.

Possible pretrained model integration

A pretrained image-classification network could be adapted for the Normal vs. Pneumonia task. Real classification will require an appropriate labeled dataset, proper model evaluation on images the model has not seen, and careful validation before any result is trusted or shown to users.
