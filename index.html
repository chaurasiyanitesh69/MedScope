Overview

A student project that will later classify chest X-ray images as Normal or Pneumonia using Python and a pretrained model. This version is the frontend only: you can upload an image, preview it, change how it is displayed and open a sample report.

AI classification is not connected yet. This application does not analyse images and shows no predictions or probabilities.

Upload an image

Workflow

  1. 1

    Upload

    Choose a PNG or JPEG sample image. It stays in your browser.

  2. 2

    Analyze

    Adjust brightness, contrast and grayscale to view the image.

  3. 3

    Review

    Open the sample report and download it as a text file.
